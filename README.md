# Personal Website

## 專案介紹
這是一個個人網站，主要用來介紹與記錄個人背景、經歷、技能與聯絡方式。

## 使用技術
- HTML5：建立網頁結構
- CSS：設計網頁版面與樣式
- JavaScript：網頁互動功能

## 專案架構
```text
├── index.html
├── styles/
│   └── style.css
├── scripts/
│   └── script.js
├── images/
│   └── IMG_profile.jpeg.jpg
└── README.md
```

## 網頁功能
- 個人介紹（About）
- 學習與工作經歷（Experience）
- 技能介紹（Skills）
- 聯絡資訊（Contact）
- 響應式網頁設計（RWD）
- 手機版導覽選單
- 自動更新頁尾年份

## 如何執行
1. 下載或 Clone 此專案。
2. 使用 VS Code 開啟專案資料夾。
3. 透過瀏覽器開啟 `index.html`。
4. 即可瀏覽網頁。

## 開發說明
本專案為個人網站，目前以靜態網頁為主， HTML、CSS 與 JavaScript 的應用。
